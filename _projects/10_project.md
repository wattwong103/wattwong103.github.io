## QGIS-MCP: AI-Assisted Geospatial Analysis

QGIS-MCP bridges the gap between geographic information systems and large language models by connecting QGIS to Claude AI through the Model Context Protocol (MCP).

### Overview

This tool enables researchers and planners to interact with geospatial data using natural language, allowing Claude to read, analyze, and manipulate spatial data directly within the QGIS environment. It streamlines workflows that traditionally require extensive scripting or manual GIS operations.

### Key Features

- **Natural language GIS operations** — Query and manipulate spatial data through conversational prompts
- **Layer management** — Load, filter, and style map layers via AI commands
- **Spatial analysis** — Perform buffer, overlay, and proximity analyses through natural language
- **Export automation** — Generate maps and export data with simple instructions

### Technical Stack

- Python plugin for QGIS
- Model Context Protocol (MCP) for Claude integration
- Supports vector and raster data formats
